# ChisaTL — Firefox Extension Community Edition

Translate manga and comics directly in your browser with **Chisa Translate**.

ChisaTL is a lightweight Firefox extension that lets you translate speech bubbles in-place or send images directly to the Chisa Translate desktop application without leaving your browser.

> [!IMPORTANT]
> The Chisa Translate desktop application must be running on your PC. This extension does not provide standalone translation capabilities.

## About This Extension

ChisaTL Firefox Extension — Community Edition is an unofficial, community-maintained adaptation of the original ChisaTL Chrome extension.

This project aims to bring ChisaTL functionality to Mozilla Firefox, allowing Firefox users to enjoy manga and comic translation directly in their browser.

The original Chrome extension was developed by the official ChisaTL developers.

## Features

| Feature | Description |
| :--- | :--- |
| **In-place Translation (TL)** | Translate speech bubbles directly on the webpage by clicking the TL button on an image. |
| **Send to Desktop App (DL)** | Send images directly to the running Chisa Translate desktop application using the DL button. |
| **Context Menu Integration** | Right-click an image to send it to the desktop application. |
| **Simple & Lightweight** | Activates its image-related features when you hover over or interact with images. |

## Requirements

- Mozilla Firefox with the ChisaTL extension installed.
- Chisa Translate desktop application installed and running on your PC.
- An active connection between the extension and the desktop application.

## How to Use

1. Launch **Chisa Translate** on your PC and keep it running in the background.
2. Open a manga or comic website in Firefox.
3. Hover over the image you want to translate.
4. Select one of the available actions:
   - **TL** — Translate speech bubbles directly on the webpage.
   - **DL** — Send the image to the Chisa Translate desktop app.

Alternatively, right-click an image and use the extension's context menu to send it to the desktop application.

## Frequently Asked Questions (FAQ)

### Why does the translated text overflow the original speech bubble?

The accuracy of text placement and fitting depends on your Chisa Translate desktop application settings. Adjust the relevant settings in the desktop app to improve text alignment and speech bubble fitting.

### Why do the TL or DL buttons stop working and turn red after a few moments?

This usually happens when the Chisa Translate desktop application is not running or the extension cannot establish an active connection to it.

Make sure the desktop application remains running in the background, even when you are not actively using it, then try the action again.

### Can I use the extension without Chisa Translate installed on my PC?

No. The extension relies on the Chisa Translate desktop application to process translation and image transfer requests. It does not include a standalone translation engine.
